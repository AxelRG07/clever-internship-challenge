Desafío inicial clever internship

1. Suma de Dígitos (suma_digitos.py)
   Descripción: Dado un número entero, calcula la suma de todos sus dígitos de forma matemática.

2. Palíndromos (palindromos.py)
      Descripción: Dado un texto o palabra de entrada verifica si se lee igual de izquierda a derecha que de derecha a izquierda.

3. Ordenamiento (ordenamiento.py)
   Descripción: Ordena una lista de números enteros en orden ascendente sin utilizar funciones nativas de ordenamiento (sort(), sorted()).
   La función retorna una nueva lista, preservando la integridad del arreglo original.

4. Pruebas automatizadas (tests.py)
   Casos propuestos por el ejercicio oficial y casos borde.
